# Routes

Public pages have no management menu.

| Path | Page |
| --- | --- |
| `/` | Home |
| `/about` | About |
| `/contact` | Contact |
| `/water-refilling` | Station info and app downloads |
| `/ice-cubes` | Ice products and order form |
| `/laundry` | Laundry services and booking |

| Path | Portal |
| --- | --- |
| `/wrs-management/login` | WRS sign-in |
| `/wrs-management` | Existing water station dashboard, POS, inventory, orders, delivery, sales |
| `/laundry-management/login` | Laundry sign-in |
| `/laundry-management` | Laundry dashboard, POS, bookings, services, expenses |
| `/overall-sales/login` | Owner sign-in |
| `/overall-sales` | Combined water, ice, and laundry figures |

Old admin paths such as `/pos` redirect to `/wrs-management/pos`.
